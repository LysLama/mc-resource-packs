# Minecraft Server Resource Packs

Consolidated and Individual Resource Packs for Minecraft Fabric 26.3 Server.

## 1. Consolidated Server Resource Pack (Recommended)
This merged package contains all visual enhancements combined into a single file with full cross-version format overlays:
* **Reimagined | Fresh Animations Patch (v1.10a)**: Official compatibility patch bridging Minecraft Reimagined and Fresh Animations models/UVs (fixes broken/shattered mob models like cows, pigs, chickens, sheep).
* **Fresh Animations (v1.10.5)**: Dynamic expressive entity animations (compatible with EMF/ETF).
* **Refined Tools (v3.0)**: High-detail 3D models for tools and weapons.
* **Fusion Collection (SuperMartijn642)**: 3D Items, Block Transitions, Connected Blocks, Connected Glass, Emissive Ores, Stacking Items.
* **Minecraft Reimagined (v1.63.5-fixed)**: Comprehensive world aesthetic overhaul, biomes, blocks, custom models.
*(Note: Enchantment Outlines has been removed).*
